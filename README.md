# 🏦 Bank Account System (C#)

A beginner‑friendly **Bank Account System** written in C#.  
This project demonstrates how to use `bool` for login authentication and basic user management.

---

## 📌 Features
- 🔐 **Login System** using username, ID, and password
- ✅ Boolean (`bool`) flag to track login status
- 🧑‍💻 User creation with ID, name, and password
- 📢 Console messages for success/failure feedback
